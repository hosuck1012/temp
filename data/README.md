# Trend Travel Judge v2 - Synthetic Dataset

이 데이터셋은 실제 최신 트렌드 사실을 기록한 자료가 아니라,
'트렌드 키워드 + 문맥 -> 여행 콘텐츠화 가능성' 판정 모델을 학습/평가하기 위한 합성 데이터입니다.

## Label 기준

- HIGH
  - 트렌드 자체가 특정 지역 방문, 관광지, 축제, 촬영지, 여행 행동, 지역 체험 등과 직접 연결됨.
  - 해당 트렌드를 보고 실제 이동/방문/예약 행동으로 이어지는 흐름이 자연스러움.

- MEDIUM
  - 트렌드 자체는 여행이 아니지만 음식, 문화, 취미, 라이프스타일, 콘텐츠 등을 통해 여행 주제로 자연스럽게 확장 가능함.
  - 추가적인 지역/장소 설정이나 기획이 필요하지만 억지 연결은 아님.

- LOW
  - 여행 목적지, 이동, 체험, 문화/지역 콘텐츠와의 연결 근거가 약함.
  - 여행 콘텐츠로 만들려면 억지스러운 설정이 필요함.

## 파일
- train_dataset.jsonl: 300개 (HIGH/MEDIUM/LOW 각 100개)
- validation_dataset.jsonl: 60개 (각 20개)
- test_dataset.jsonl: 60개 (각 20개)
- runtime_candidates.jsonl: 30개, label 없는 실행/추론 연습용
